# Governance

PEPTOMA protocol parameters are governed on-chain by $PEPTM stakers via the [Governance page](https://peptoma.xyz/governance).

## Voting

- Cast YES or NO on active proposals
- Weight is determined by staking tier (FREE 1×, RESEARCHER 1.5×, PRO 2×, LAB 3×)
- One vote per wallet per proposal
- Proposals pass when quorum is reached and YES votes exceed NO votes

## Proposal Categories

| Category | Description |
|---|---|
| `reward_rate` | Changes to token reward amounts per action |
| `tier_requirement` | Changes to staking thresholds for tier upgrades |
| `scoring` | Changes to AI scoring weights or methodology |
| `policy` | Platform-level policy changes |
| `other` | Miscellaneous governance actions |

## Proposal Lifecycle

`pending` → `active` → `passed` or `failed`

Active proposals have an `endsAt` deadline visible on the governance page.
